## 换照片的两种方式
1. **放文件夹**：把实拍按 `photos/p1.jpg … p10.jpg` 命名、群二维码命名为 `photos/qrcode.png`（或 .jpg）放入 photos/，运行 `python3 render.py`，自动载入并导出。
2. **在浏览器里**：双击打开 `排版源稿.html` → 点击任一「实拍照片」框选图 → 拖动调整取景、Ctrl+滚轮缩放、双击复位 → 「开启文字编辑」可改字 → 「保存编辑后的HTML」。把下载的HTML放回本文件夹（与 assets/ 同级），运行 `python3 render.py 下载的文件名.html` 即导出PNG。

## 删除用不到的照片框（没有素材时）
1. 双击打开 `排版源稿.html`，点左侧工具栏「开启编辑（文字 / 照片框）」。
2. 每个照片框 / 二维码框右上角出现「替换｜清除照片｜删除此框」，点「删除此框」即整框移除，排版自动收拢：
   - 并排双图删一张 → 剩下那张撑满整行（高 460px）；两张都删 → 整行消失，不留空白；
   - 删讲师竖图 p1 → 讲师信息占满整行；删二维码 → 招新卡片保留文案、去掉“长按识别”提示。
3. 误删：工具栏「已删除照片位」列表里点「恢复 pN」，或「撤销删除」/「全部恢复」。删除前已放的照片会一并恢复。
4. 点「保存编辑后的HTML」，删除状态随文件保存（`data-removed` 属性），重新打开仍保持。
5. 把保存的HTML放回本文件夹，运行 `python3 render.py 排版源稿-已编辑.html`，被删的框不会出现在长图和分段图中，分段按章节自动重新计算。
注：编辑按钮与工具栏只在浏览器编辑界面出现，导出PNG中不会出现。「清除照片」只清空图片、保留框；「删除此框」才是移除整框。

## 导出
```
pip install playwright && python3 -m playwright install chromium   # 或使用本机 Chrome
python3 render.py                 # 用 排版源稿.html + photos/
python3 render.py 已编辑.html      # 用保存过的编辑稿
python3 render.py --scale 1.2     # 1080 宽高清版
```
输出覆盖到 `成品图片/`（会先清掉旧的分段图）。分段规则：`data-seg` 前两位相同的 section 合为一张。
